Interactive Weaving Draft Generator

Experiment with different loom configurations. Choose the number of frames, pedals, warps and weft cycles, then generate a random, loom-reproducible weaving draft.

Each generated draft contains four binary matrices: threading, tie-up, treadling and drawdown. The drawdown is generated using

Drawdown = Treadling × Tie-upT × Threading

The generator also imposes basic physical constraints of the loom. For example, each warp thread is assigned to exactly one frame.
